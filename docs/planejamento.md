Problema: a pessoa tem vários links importantes (LinkedIn, GitHub, portfólio, e-mail), mas as redes sociais só permitem um link na bio.

Usuário: você, e quem visita o seu perfil, por exemplo um recrutador.

Histórias de usuário. Uma história segue o modelo Como [quem], quero [o quê], para [por quê]:

Como visitante, quero ver nome, foto e uma frase de apresentação, para saber de quem é a página.
Como visitante, quero clicar em botões com os links principais, para acessar as redes da pessoa.
Como visitante, quero alternar entre tema claro e escuro, para ler com conforto.
Como visitante no celular, quero que a página se adapte à tela, para não precisar dar zoom.

Escopo da versão 1 (MVP):

✅ DENTRO	                       ❌ FORA (fica para depois)
Foto, nome, bio curta	            Painel para editar os links
4 a 6 botões de links	            Contador de cliques
Botão de tema claro/escuro	        Login, banco de dados
Layout para celular e desktop	    Várias línguas
